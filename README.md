# 🐍 Ultimate Snake Game

A modern and feature-rich Snake Game built using **HTML, CSS, and Vanilla JavaScript**.

This project demonstrates strong front-end development skills including game logic, animations, sound integration, local storage, AI logic, and responsive mobile controls.

---

## 🎮 Features

- 🎯 Classic Snake gameplay
- 🧠 AI Snake Mode
- 🏆 Leaderboard System (Local Storage)
- 📈 Dynamic Speed Increase based on score
- ⏱ Game Timer
- 🎚 Difficulty Levels (Easy / Medium / Hard)
- 🔊 Sound Effects (Web Audio API)
- 📱 Mobile Touch Controls
- ⏸ Pause / Resume System
- 🚪 Exit & Restart Options
- 🎨 Grid Background & Clean UI
- 💾 Score Saving with Player Name

---

## 🛠 Technologies Used

- HTML5 Canvas
- CSS3
- JavaScript (ES6)
- Web Audio API
- LocalStorage API
